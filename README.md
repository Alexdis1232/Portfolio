# Portfolio

## Разработка

```bash
npm install
npm run dev
```

Сайт: [http://localhost:3000](http://localhost:3000)

## Тест с телефона (локальная сеть)

1. ПК и телефон в одной Wi‑Fi сети.
2. Запусти сервер, доступный в сети:

   ```bash
   npm run dev:mobile
   ```

3. Узнай IP компьютера (PowerShell):

   ```powershell
   ipconfig
   ```

   Нужен **IPv4** активного Wi‑Fi, например `192.168.1.42`.

4. На телефоне открой в браузере:

   ```
   http://192.168.1.42:3000
   ```

   Подставь свой IP.

### Если не открывается

- Разреши Node.js в фаерволе Windows (частная сеть).
- Отключи VPN на ПК и телефоне.
- Избегай гостевой Wi‑Fi — устройства могут быть изолированы.

### Вне домашней сети

Можно пробросить порт через [ngrok](https://ngrok.com):

```bash
npm run dev
npx ngrok http 3000
```

Открой выданную `https://…` ссылку на телефоне.
